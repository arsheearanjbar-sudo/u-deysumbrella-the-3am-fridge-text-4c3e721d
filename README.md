A deterministic program that writes the one line a smart fridge would text its owner at 3am — a small machine with a logbook, an opinion, and no shame about sharing it at 3am. The line is fixed, original, and 113 characters: a fridge that has been counting the nights, not a joke about milk, ice, or a door left open.

## Run it

```sh
python3 main.py
```
